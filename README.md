# SpaceFinder

See what's using your drive space on Windows, and get it back.

**[Download SpaceFinder for Windows](https://github.com/alid0n/spacefinder-releases/releases/latest/download/SpaceFinder.exe)** (Windows 10 and 11, 64-bit)

SpaceFinder is a single program file. There's nothing to install: download it and double-click to run.

## What it does

- **Installed programs by size.** Desktop, Microsoft Store, Steam and Epic apps in one list, with when each was last used and a one-click uninstall.
- **Quick wins.** Temporary files, crash dumps, browser caches and download caches, measured and cleared in one place.
- **Biggest folders and files.** Scan a drive and click into any folder to see what's inside, with a filter for videos, disk images, archives and more.
- **What grew.** Scans are saved, so SpaceFinder can show which folders have been filling up since last time.
- **Developer clutter and duplicates.** Finds rebuildable folders like `node_modules` and build output, old Android emulators, and identical copies of large files.
- **Plain-English explanations.** Every recognised file and folder says what it is, with a colour-coded rating: safe to delete, check first, or don't delete.
- **Move to another drive.** Move large folders to a second drive, optionally leaving a link behind so programs still find them.
- **Low-space alert.** An optional tray icon warns you before your drive fills up.
- **Dark and light themes.**

## Careful by design

- Windows' own files, and the folders programs need to run, are protected from deletion.
- Files and folders you remove from the folder, file and duplicate lists go to the Recycle Bin.
- Quick wins and Developer clutter only clear caches and rebuildable files, and always show what will be removed before asking you to confirm.
- SpaceFinder doesn't connect to the internet. Nothing about your files leaves your PC.

## First launch

SpaceFinder is new and not yet code-signed, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**.

Some areas, like Windows' own temporary files, can only be cleared as administrator. Use the **Run as administrator** button in the app when you need them.
